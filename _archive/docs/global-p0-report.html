本次开发围绕"海外官网多语言AI客服承接 + 成单回传广告平台"这一个 MVP 场景，完成了后端核心服务、海外官网挂件、营销落地页、管理后台、资质申请指南五大模块。所有代码已上传 GitHub（HiAeo/workhogee, main 分支），后端启动验证通过，所有新增 API 端点返回 200。

2完成的功能清单

任务1：多语言引擎（后端）

  • 支持 8 种语言：English、Spanish、French、German、Japanese、Korean、Portuguese、Arabic（RTL）
  • 自动语言检测：浏览器语言优先 → ipapi.co IP 地理定位（3秒超时降级）→ 默认 en
  • DeepSeek 大模型实时翻译（无第三方翻译 API，零额外费用）
  • 多语言话术模板 CRUD（文件存储 + PostgreSQL 表定义）
  • 管理后台中/英 UI 文案字典

任务2：海外官网挂件 widget-global.js

  • 8 语言 UI 自动切换（约 40 个文案 key），阿拉伯语 RTL 布局镜像
  • 国际化视觉风格（Intercom/Drift 参考），支持自定义品牌色
  • 全部内联 SVG 图标（零 emoji），助手/用户头像 SVG 化
  • Cookie 同意横幅（GDPR/CCPA），多语言文案，同意/拒绝状态持久化
  • 离线消息队列（localStorage），30秒轮询重连，自动重发
  • 访客信息收集表单（姓名/邮箱/公司/国家，国家自动检测）
  • 意向等级 A/B/C 标签展示，高意向 SVG 火焰通知
  • 对话功能：打字指示器、时间戳、基础 Markdown 渲染、历史恢复
  • 暴露全局 API：init/open/close/setLanguage/showCookieBanner/destroy

任务3：广告回传（后端）

  • Meta Conversions API 完整实现（graph.facebook.com v18.0，SHA-256 用户哈希）
  • Google Ads Enhanced Conversions / TikTok Events API 接口骨架预留（not_implemented）
  • 广告平台配置 CRUD，敏感字段（accessToken）掩码返回
  • 回传日志记录（平台/事件/状态/响应/时间戳）
  • 线索成交自动回传：convertLeadAndSend() 先更新线索状态再逐平台回传
  • 平台连接测试端点（发送测试事件）

任务4：合规基础（后端+前端）

  • Cookie 同意管理（记录/查询，访客维度持久化）
  • 数据删除请求流程（创建/查询，pending → processing → completed）
  • 数据保留策略（默认 90 天可配置，过期清理端点，扫描对话文件）
  • PII 脱敏（邮箱 j***@example.com，电话 138****5678）
  • AES-256-CBC 对话数据加密/解密（scrypt 派生密钥，Node 内置 crypto）
  • Do Not Track 请求头检测
  • widget-global.js 集成 Cookie 同意横幅

5如何测试

5.1 后端启动与 API 测试

  • 启动：cd ai-agent && node src/app.js（默认端口 3000）
  • 健康检查：浏览器访问 http://localhost:3000/api/health
  • 语言列表：http://localhost:3000/api/i18n/languages（应返回8种语言）
  • 合规设置：http://localhost:3000/api/compliance/settings
  • 广告平台：http://localhost:3000/api/ad-platforms
  • 翻译测试（POST）：curl -X POST http://localhost:3000/api/i18n/translate -H "Content-Type: application/json" -d "{\"text\":\"Hello\",\"from\":\"en\",\"to\":\"es\"}"

5.2 海外挂件测试

  • 创建测试 HTML 文件，嵌入：<script src="widget-global.js" data-api-url="http://localhost:3000" data-language="auto"></script>
  • 浏览器打开测试页，右下角应出现对话按钮
  • 测试多语言：修改 data-language="ar" 验证 RTL 布局
  • 测试离线：断开后端后发送消息，验证离线队列和重连
  • 测试 Cookie 横幅：清除 localStorage 后刷新页面

5.3 管理后台测试

  • 浏览器访问 http://localhost:3000/global-admin.html
  • 测试侧边栏 5 个页面切换
  • 测试中/英语言切换按钮
  • 测试 Modal 弹出（添加平台、标记成交、新建模板）
  • 测试 Switch 开关组件

5.4 营销页面测试

  • 浏览器直接打开 global.html（file:// 协议即可）
  • 验证 11 个板块全部渲染，滚动动画正常
  • 验证 FAQ 手风琴展开/收起
  • 验证响应式（缩小窗口到移动端宽度）
  • GitHub Pages 部署后访问 https://www.workhogee.com/global.html

8技术决策记录

  • 翻译用 DeepSeek 而非第三方翻译 API：零额外费用，质量足够，统一模型调用链路
  • Meta CAPI 优先实现：出海卖家最常用的广告平台，P0 聚焦
  • 开发环境 JSON 文件存储：与现有项目一致（database.enabled=false），同时提供 PostgreSQL 表定义供生产使用
  • 零新增 npm 依赖：所有 HTTP 调用用 Node 内置 https，加密用内置 crypto，避免依赖膨胀
  • 管理后台独立单文件：global-admin.html 不修改现有国内版后台，独立入口，后续可合并
  • 挂件纯原生 JS IIFE：与国内版 widget.js 一致，零依赖，可直接嵌入任意网站
  • 不破坏现有国内版：所有新增为增量，现有 widget.js、服务、路由、后台均未修改功能
