1项目背景

产品定位

GEO 伙计特别版是 WorkHogee 的一个 Add-on 模块，不是独立产品。它作为现有 AI 客服/伙计产品的获客前端增量，回答一个问题："当客户在 ChatGPT / 文心一言 / 豆包里问'AI 客服哪家好'时，AI 推荐的为什么是你而不是竞品？"

差异化

市面上已有 GEO/AI 搜索监测工具（如 Profound、Otterly 等），但它们大多只做监测看板——告诉你"你的品牌被提到了几次"，仅此而已。WorkHogee GEO 伙计的差异化在于做闭环：

  • 监测：追踪品牌在各 AI 引擎中的提及、排名、情感
  • 种草：自动生成 E-E-A-T 内容，让 AI 更愿意引用你
  • 承接：归因落地页接住从 AI 过来的流量，自动带参归因
  • 成交：落地页内嵌伙计对话挂件，销售线索直接进伙计
  • 回传：成交数据回流到 GEO 周报，算出每个关键词的真实 ROI

目标客户

  • 本地 / 连锁中小企业：在国内市场，预算有限，但需要在 AI 搜索时代保住品牌曝光
  • 中国出海 DTC 卖家：面向 ChatGPT、Perplexity、Google AI Overviews 做海外 GEO，与出海专版（global）协同

6待办事项和后续规划

P1 规划

  • 真实 AI 搜索引擎 API 接入：当前监测数据为模拟/启发式生成，P1 接入 ChatGPT API、Perplexity API、Google AI Overviews 等真实接口
  • 更多内容模板：当前 4 类模板（科普/对比/FAQ/案例），P1 扩展到 8-10 类，支持行业模板包
  • 落地页可视化编辑器：当前落地页基于固定模板，P1 提供拖拽式可视化编辑
  • 竞品对标看板：同一查询下你和 N 个竞品的横向对比趋势
  • 负面提及告警：负面情感提及自动推送企微/飞书告警
  • 多语言 GEO：与出海专版 i18n 打通，支持英文/日文/西语等多语言 GEO 监测和内容生成
  • 自动化测试：为 4 个 GEO 服务编写单元测试和集成测试

已知限制

  • 限制 当前监测结果为模拟数据，不代表真实 AI 引擎回答。需要在 P1 接入真实搜索 API 后数据才有业务决策价值。
  • 限制 内容生成依赖现有 DeepSeek 链路，长文生成稳定性待观察。
  • 限制 管理后台部分图表数据使用前端 mock，需对接真实 API（调用点已标注 TODO）。
  • 限制 落地页 A/B 测试分流为按 Cookie 哈希分流，尚未做统计显著性自动计算。

7部署说明
